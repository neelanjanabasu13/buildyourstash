# Brand slots

The app reads these five files from this folder. Drop a new file with the same
name here and it appears in the app on the next load, no code change needed.
Each file is a cut-out on a transparent background so it sits cleanly on the
cream page.

| File | Where it shows | Made from |
| --- | --- | --- |
| logo.png | header, top left | Stash-brand-logo.png (the full lockup: crow, STASH, tagline) |
| krowe-standing.png | home hero, beside the headline | Krowe-still-frame1.png |
| krowe-thinking.png | sweep progress panel | Krowe-still-frame3.png (laptop + lightbulb) |
| krowe-sleeping.png | "nothing in your pile" state and "nothing found" verdicts | Krowe-still-frame5.png |
| krowe-shipped.png | REVIVE NOW verdict card | Krowe-still-frame6.png |

The browser-tab icon is /public/favicon.png: the crow bust from logo.png,
cropped and padded to a square, because the tagline is too small to read at
tab size.
